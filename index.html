Exhibit A

AI-Based Insider-Threat Detection Framework

In which the model learns to trust absolutely no one — least of all you.

Pythonscikit-learnXGBoostSHAPCustom Data Structures

A dual-model anomaly framework built on a real, unlabeled dataset of 10K messages across 942 users — combining drift scoring with Isolation Forest for cross-validated detection, then layering a RandomForest / XGBoost classifier with SHAP explainability on top of a rare-event, sub-5%-positive problem. Four custom data structures cut ranking cost from O(N log N) to O(N log K). On top of the models sits a read-only investigation agent that chains four evidence sources — risk history, messages, audit logs, governance docs — into a single LLM-reasoned recommendation, with a rule-based fallback so the system never goes dark.

Exhibit B

Sentinel Rate Limiter

Redis's very polite way of telling someone to calm down.

RedisLuaLangGraphClaude APIPrometheusPostgreSQL

A high-throughput abuse-detection layer that eliminates race conditions with atomic, Lua-scripted sliding-window rate limiting on Redis, escalating repeat offenders through a tiered auto-block ladder. An LLM risk-assessment agent — LangGraph plus the Claude API, few-shot-prompted for structured JSON — sits alongside a deterministic fallback so the service never drops to zero availability. Escalation thresholds were tuned the way a growth team would tune a funnel: hypothesis, A/B-style comparison, adjust. Shipped as a fully observable, CI/CD-deployed three-tier service with Prometheus metrics and a tamper-resistant audit trail.

Exhibit E

Performance Benchmarking — DSA Variants

Proof that Big-O notation has feelings, and TreeMap's are hurt.

A JMH microbenchmark harness pitting bucket sort against TreeMap sort and Java's TimSort baseline across datasets up to 10M elements. On a bounded integer range, bucket sort holds a consistent ~3.2× throughput edge over TreeMap sort from 100K to 10M elements — evidence that the gain comes from the algorithm, not from cache effects at any particular scale.
