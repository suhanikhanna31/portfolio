Signal: Behavioral & Psycholinguistic Insider-Threat Detection

In which “just look at the messages” becomes a full ML + governance pipeline.

🐈hmm.
IBM · AI/ML InternPythonscikit-learnXGBoostPyTorchFastAPI

Built an insider-threat detection pipeline processing 50K+ real CERT records through consent-gated anonymization and stylometric feature engineering; served through FastAPI/Vercel with Neon Postgres under a 750MB deployment constraint. Applied weighted z-score drift scoring, an incremental Welford-style variant, stratified train/test splits, leakage prevention and AUC/precision/recall/F1 evaluation; compared Random Forest, XGBoost and a PyTorch MLP with self-training pseudo-labeling. The deployment path uses offline training plus batch inference, with four custom data structures for sub-linear performance and CI through GitHub Actions.
