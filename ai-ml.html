EXHIBIT A · WORK EXPERIENCE

Signal: Behavioral & Psycholinguistic Insider-Threat Detection

The ML version: measure drift, compare models, make the evidence inspectable.

IBM · AI/ML InternPythonHugging FacePyTorchXGBoostMLflowRAGLangGraph

Built and deployed an end-to-end insider-threat pipeline on real CERT data, combining linguistic/stylometric feature engineering, weighted drift scoring, supervised and unsupervised models, MLflow tracking, FastAPI serving and PostgreSQL persistence. The current real-data run evaluates 10K messages across 942 users: 654 messages (6.5%) were drift-flagged, with mean non-zero drift 0.121 and maximum 3.83. The system also adds Hugging Face sentiment analysis, TF-IDF/cosine RAG and a read-only investigation agent that turns multiple evidence sources into a human-reviewable recommendation.

EXHIBIT B · PERSONAL PROJECT

Transaction Anomaly Notifier

Because “flag suspicious transactions” deserved a whole service.

FastAPIPyTorchXGBoostMLflowPostgreSQLRedisCeleryAWS Lambda

Built a transaction-fraud detection API that combines five independent signals into a 0–100 risk score, persists PostgreSQL audit logs and dispatches non-blocking email/Slack alerts through Celery and Redis. It supports single and batch scoring, with a 100-transaction batch cap, Docker Compose, GitHub Actions CI, and an AWS Lambda/API Gateway deployment path. Experiments use Random Forest, XGBoost and a PyTorch MLP with MLflow-tracked artifacts.

30–60s start time: first request may wake the free-tier deployment.
